# CPS Tester

A simple Clicks Per Second Tester built with PyQT5.

## Has

- Many test durations:
    1 second, 2 seconds, 3 seconds, 5 seconds, 10, seconds, 30 seconds, **Marathon**(2 minutes)

- Time starts on first click

## Requirements

- Python >3.8
- PyQT5

## Installation

### Arch and Arch Based:

```console
sudo pacman -S python-pyqt5
```

### Debain and Debian Based:

```console
sudo apt install python3-qt5
```

### Fedora or RHEL Based:

```console
sudo dnf install python3-qt5
```

### OpenSUSE:
```console
sudo zypper install python3-qt5
```

### Windows (Via pip):
```console
pip install PyQt5
```

### MacOS (Via Homebrew):
```console
brew install pyqt
```

## To run this code:

Download the file `CPsTest.py` and run
```console
python CPsTest.py
```
